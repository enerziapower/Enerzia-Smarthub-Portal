**Key Technical Concepts**
-   **Background Job Processing:** An architecture to handle long-running tasks by returning a job ID immediately and allowing the client to poll for status. This is crucial for avoiding HTTP timeouts.
-   **Cloudflare Timeout (HTTP 524):** The specific production error being solved. It occurs when a synchronous request to the origin server takes longer than Cloudflare's timeout limit (typically 100 seconds).
-   **Data Migration & Diagnostics:** Using one-off scripts to analyze and repair data integrity issues in a production environment (e.g., moving images from an ephemeral file system to a persistent database).
-   **Graceful Degradation:** Designing a system to handle failures without crashing. In this case, generating PDFs with placeholders for missing images.
